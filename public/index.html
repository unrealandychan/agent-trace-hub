          ⚡ Why Latency Matters & How We Eliminate It (< 0.2ms Overhead)
        

        

          In interactive coding loops, running heavy synchronous hook scripts (e.g., launching a Python interpreter or making blocking network requests on every tool execution) adds 50ms – 200ms per turn. Over 30 tool calls, this adds 3 to 6 seconds of noticeable lag.
        


        

          

            

              AGY Hook Optimization
            

            

              AGY executes commands synchronously. Our fast-trace.sh script immediately captures stdin and writes to kernel buffer in ~0.1ms, returning {} instantly.
            

          


          

            

              Claude Code Optimization
            

            

              Claude Code natively supports "async": true in settings.json. Claude Code forks the hook process in the background without awaiting its exit, imposing 0ms blocking latency.
            

          


          

            

              Pi Agent Optimization
            

            

              Pi extensions run in Node.js. pi-tracer.ts uses non-blocking fire-and-forget I/O on Node's async event loop, never pausing the agent loop.
            

          


          

            

              Cursor IDE Optimization
            

            

              Cursor Agent saves native turn logs in ~/.cursor/projects/*/agent-transcripts/. AgentTrace Hub passively tails these asynchronously with 0.0ms overhead on Cursor.
            

          

        


        
        

          

            Test Live Telemetry Ingestion
            Send an instant test tool event to verify the collector server and measure round-trip latency
          

          
        

        

      


      
      

        
        

          

            

              1. AGY Configuration
              .agents/hooks.json
            

            
{
  "agent-trace-hub": {
    "enabled": true,
    "PostToolUse": [{
      "matcher": ".*",
      "hooks": [{
        "type": "command",
        "command": "/home/arch/agent-trace-hub/hooks/fast-trace.sh agy post_tool"
      }]
    }],
    "Stop": [{
      "type": "command",
      "command": "/home/arch/agent-trace-hub/hooks/fast-trace.sh agy stop"
    }]
  }
}

          

          
Saves to your project root under .agents/hooks.json.

        


        
        

          

            

              2. Claude Code
              .claude/settings.json
            

            
{
  "hooks": {
    "PostToolUse": [{
      "matcher": ".*",
      "hooks": [{
        "type": "command",
        "command": "/home/arch/agent-trace-hub/hooks/fast-trace.sh claude post_tool",
        "async": true
      }]
    }],
    "Stop": [{
      "matcher": "",
      "hooks": [{
        "type": "command",
        "command": "/home/arch/agent-trace-hub/hooks/fast-trace.sh claude stop",
        "async": true
      }]
    }]
  }
}

          

          
Notice "async": true for 0ms blocking wait.

        


        
        

          

            

              3. Pi Agent
              .pi/extensions/tracer.ts
            

            
// Run pi with:
// pi -e /home/arch/agent-trace-hub/hooks/pi-tracer.ts

import type { ExtensionAPI } from "@earendil-works/pi-coding-agent";

export default function(pi: ExtensionAPI) {
  pi.on("tool_result", (event) => {
    // Non-blocking asynchronous telemetry
    postTelemetry("pi", "post_tool", event);
  });
  pi.on("agent_settled", () => {
    postTelemetry("pi", "stop", {});
  });
}

          

          
Run with pi -e .../pi-tracer.ts or place in ~/.pi/agent/extensions/.
